# Paper build

```bash
bash build.sh        # pdflatex + bibtex + pdflatex x2 -> main.pdf
```

- `main.tex` is self-contained (standard `article` class) so it builds anywhere with a normal
  LaTeX install. To target ACL/ARR, swap the preamble for `\usepackage{acl}` as in the group's
  prior submissions; the body is class-agnostic.
- Table~\ref{tab:flip} auto-includes `../../Experiment/analysis/flip_rates.tex`, regenerated by
  `python -m src.pipeline --stage 5`. Until the real run, `[PLACEHOLDER]` marks every number to
  fill from `Experiment/analysis/`.
- `custom.bib` holds the core citations from the venue survey; author lists marked `Anonymous`
  need completing at camera-ready.
